# Cat Game (Brackeys Game Jam 2026.1)

2D-платформер, разработанный в команде в рамках джема Brackeys Game Jam 2026.1.

🎮 **Поиграть в билд на itch.io:** https://checoffix.itch.io/abandoned

### Что реализовано по кодовой части:
- **Контроллер игрока:** механика плавного перемещения, прыжки, карабканье по поверхностям (`PlayerClimbing`), обработка урона и смертей (`PlayerDeathHandler`).
- **Камера и окружение:** управление виртуальной камерой через Cinemachine (`CinemachineOffsetControl`, `CameraOrthographicController`), эффект тряски экрана (`ScreenShake`), многослойный параллакс фона (`Parallax`).
- **Игровой цикл:** система чекпоинтов, триггеры переходов между зонами, менеджер таймингов (`TimeManager`).
- **Аудио и UI:** централизованный `MusicManager` с переключением фоновых треков через AudioMixer, меню настроек звука и навигация по интерфейсу.

**Стек:** Unity, C#, 2D URP, Cinemachine, Git (командная разработка на 2 человек).
